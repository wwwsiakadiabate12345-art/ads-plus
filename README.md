# 🚀 ADS+ - Plateforme de Vente en Ligne

## Fonctionnalités

✅ **Authentification Utilisateur**
- Inscription et connexion sécurisées
- Sauvegarde des données en localStorage
- Gestion de compte utilisateur

✅ **Panier et Commandes**
- Ajout/suppression de produits
- Calcul automatique du total
- Historique des commandes
- Paiement avec formulaire

✅ **Produits**
- 14 produits préchargés
- 3 catégories (Électronique, Vêtements, Maison)
- Tous les prix en **Francs CFA**

✅ **Recherche et Filtres**
- Barre de recherche en temps réel
- Filtres par catégorie

✅ **Design**
- Interface responsive (mobile & desktop)
- Design moderne avec gradients
- Navigation fluide

## Démarrage Rapide

1. Clonez le repository
2. Ouvrez `index.html` dans un navigateur
3. Profitez! 🎉

## Technologies

- HTML5
- CSS3
- JavaScript (Vanilla)
- localStorage (pour la persistence)
